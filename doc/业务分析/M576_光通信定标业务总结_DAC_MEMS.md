# M576 光通信定标业务总结：DAC / MEMS 定标算法理解

> 适用背景：M576 光通信设备中的 MEMS / DAC 定标、寻峰、归零、功率映射、定标算法设计与业务理解。

---

## 1. 核心结论

光通信定标的本质，不只是“调一个 DAC 值”或“找一个最大功率点”，而是在建立一个稳定、可追溯、可补偿的映射关系：

```text
控制量 → 物理状态 → 光学结果 → 测量值
```

对于 M576 中的 MEMS 定标，可以抽象为：

```text
DAC(X, Y)
  ↓
MEMS 镜面偏转 / 光斑位置
  ↓
光耦合效率 / 衰减 / 输出功率
  ↓
PD / OPM 测量值
```

因此，MEMS 定标本质上是在寻找并维护一个二维光学响应面：

```text
Z = f(X, Y)
```

其中：

- `X / Y` 是 DAC 控制坐标；
- `Z` 是光功率、耦合效率或衰减结果；
- 定标目标是找到稳定、可重复、可补偿的最佳工作点。

---

## 2. 为什么要定标 DAC

DAC 定标不是单纯校准 DAC 芯片，而是校准：

```text
DAC 码值 → MEMS 实际物理位置 → 光学功率结果
```

理论上，同一个 DAC 值应该对应同一个 MEMS 偏转角度。但实际中会受到以下因素影响：

- 温度变化；
- MEMS 结构应力释放；
- 静电驱动中的电荷捕获；
- 器件老化；
- 光纤、透镜、封装、PD 链路偏差；
- 模拟电路和 ADC / DAC 链路误差。

所以实际情况是：

```text
同一个 DAC 值 ≠ 永远对应同一个光学状态
```

定标的作用，就是重新建立这个映射关系，让设备知道：

```text
想达到某个光学状态，应该输出哪个 DAC 值
```

---

## 3. MEMS 为什么需要周期归零和重新定标

MEMS 是典型的开环或弱闭环系统。很多情况下系统并不知道 MEMS 镜片的真实位置，只能通过 PD 功率变化间接判断。

周期归零的本质不是简单“回到中心点”，而是重新定义坐标原点：

```text
重新确认 X=0, Y=0 的参考位置
```

它的关键作用包括：

1. **重建参考坐标系**  
   长时间运行后，MEMS 零点可能漂移。归零用于重新建立 DAC 坐标和物理位置之间的基准关系。

2. **消除累积误差**  
   每次寻峰或移动都可能产生微小误差，长期运行后误差会累积。归零相当于做一次系统误差重置。

3. **缓解温漂和应力漂移**  
   温度、封装应力、材料热膨胀都会导致峰值位置变化。

4. **释放静电残留影响**  
   对静电驱动的 MEMS，长期停留在某个位置可能导致电荷捕获，造成同一 DAC 下偏转状态变化。

所以 M576 的 MEMS 归零和重新定标，本质是保证：

```text
当前 DAC 坐标系仍然能够代表真实光学响应面
```

## 4. 传统一维扫描 + 二次拟合的业务局限

当前很多 MEMS 定标算法采用：

```text
固定 Y → 扫描 X → 二次拟合找 X Peak
固定 X → 扫描 Y → 二次拟合找 Y Peak
```

这种方法本质是用一维切片去推断二维响应面。它在理想抛物面或近似高斯面的局部区域内有效，但存在明显局限。

---

### 4.1 峰值可能不在扫描线上

真实目标是：

```text
argmax f(X, Y)
```

而一维扫描实际求的是：

```text
argmax f(X, Y0)
argmax f(X0, Y)
```

如果固定的扫描线没有穿过真实峰值，那么拟合再准确，也只能得到扫描线上的局部最优点，而不是真正二维峰值。

---

### 4.2 X / Y 轴可能存在耦合

理想模型假设：

```text
Z = a - b(X-X0)^2 - c(Y-Y0)^2
```

但实际 MEMS 光学响应面可能存在耦合项：

```text
Z = a + bX + cY + dX² + eY² + fXY
```

其中 `fXY` 表示 X 轴和 Y 轴不是完全独立的。

这意味着：

```text
移动 X 轴时，光斑可能同时发生 Y 方向偏移
移动 Y 轴时，也可能影响 X 方向响应
```

一维扫描无法充分表达这种耦合关系，因此可能产生寻峰偏差。

---

### 4.3 平顶、宽光斑和小光斑都会影响拟合稳定性

对于大光斑：

```text
峰值区域可能很平，曲率很小
```

二次拟合公式：

```text
Peak = -B / 2A
```

当 `A` 很小时，少量噪声就可能导致 Peak 位置大幅跳动。

对于小光斑：

```text
响应曲线很陡，采样步长稍大就可能越过真实峰值
```

因此，不同光斑尺寸会导致一维拟合出现不同类型的误差：

- 大光斑：峰值不敏感，拟合容易受噪声影响；
- 小光斑：峰值过窄，容易漏采真实峰值；
- 畸变光斑：曲线不满足二次模型假设。

---

### 4.4 多峰和假峰问题

由于反射、串扰、边缘效应、光路畸变等原因，功率曲线可能出现多个局部峰值。

一维二次拟合默认只有一个峰，容易把局部峰误认为全局峰。

这会导致：

```text
算法找到的是“拟合峰”
而不是“真实最佳光学耦合点”
```

---

### 4.5 扫描期间响应面可能已经漂移

一维扫描通常假设：

```text
扫描过程中响应面是静止的
```

但实际 MEMS 可能在温漂、应力释放、电荷捕获影响下持续漂移。

因此，扫描开始时的响应面和扫描结束时的响应面可能已经不同。

---

## 5. M576 定标算法的深度理解

M576 的 MEMS 定标不能只看成“找最大功率点”，更应该看成：

```text
在有限采样、有限时间、带噪声、带漂移的条件下，重建局部二维响应面，并找到稳定工作点
```

因此，算法核心不是单点寻峰，而是以下三个能力：

### 5.1 建模能力

从：

```text
一维曲线拟合
```

升级为：

```text
局部二维响应面拟合
```

例如使用：

```text
Z = a + bX + cY + dX² + eY² + fXY
```

这样可以识别：

- 峰值位置；
- X / Y 耦合；
- 曲率大小；
- 响应面是否稳定；
- 是否存在异常峰或拟合病态。

---

### 5.2 判定能力

定标算法不仅要输出 Peak，还应该判断结果是否可信。

建议关注以下指标：

| 指标 | 业务意义 |
|---|---|
| 峰值功率 | 判断当前耦合质量 |
| 曲率 | 判断峰值是否尖锐或平坦 |
| 拟合残差 | 判断模型是否符合真实采样 |
| X/Y 耦合项 | 判断坐标轴是否独立 |
| 峰值偏移量 | 判断是否发生漂移 |
| 重复性 | 判断定标是否稳定 |
| 扫描耗时 | 判断生产效率 |

---

### 5.3 补偿能力

定标的最终价值不是“测一次”，而是形成可使用的补偿模型。

例如：

```text
DAC → 光功率
DAC → 衰减量
DAC(X,Y) → 最佳耦合点
Temperature → Peak Offset
Time → Drift Offset
```

这些补偿模型可以用于：

- 初始化定位；
- 快速寻峰；
- 长时间挂机补偿；
- 异常检测；
- 生产数据追溯；
- 设备一致性分析。

---

## 6. 光通信定标的通用性

光通信领域很多定标业务本质类似，都是建立控制量、物理量和测量量之间的映射。

| 对象 | 控制量 | 输出 / 测量量 | 定标本质 |
|---|---|---|---|
| MEMS | DAC X/Y | 光功率 / 耦合效率 | 二维响应面寻峰 |
| VOA | DAC / Voltage | 衰减量 | DAC 到 Attenuation 映射 |
| EDFA | Pump Current | Gain / Output Power | 电流到增益映射 |
| TEC | DAC / Current | 温度 | 控制量到温度映射 |
| Laser | Bias / Temperature | 功率 / 波长 | 电流/温度到光学状态映射 |
| OPM | ADC / PD Current | dBm | 测量值到真实功率映射 |

所以可以统一抽象为：

```text
Calibration = 建立、验证、修正 Input → Optical State → Measurement 的映射关系
```

MEMS 的特殊性在于：

```text
普通定标多是一维曲线
MEMS 定标是二维甚至多维响应面
```

因此 MEMS 定标天然更复杂。

---

## 7. 对 M576 定标业务的架构化总结

M576 定标业务可以分成四层：

```text
1. 数据采集层
   固件扫描 DAC，采集 PD / OPM 功率序列

2. 算法建模层
   一维拟合、二维拟合、响应面建模、异常判断

3. 业务判定层
   判断峰值是否有效、定标是否通过、是否需要重新扫描或归零

4. 补偿应用层
   生成 LUT / 参数表 / 补偿模型，用于后续运行和生产追溯
```

---

## 8. 从一维算法到二维算法的演进方向

当前一维扫描 + 二次拟合可以作为基础算法，但后续可以演进为：

```text
粗扫定位
  ↓
局部二维采样
  ↓
二次曲面拟合
  ↓
峰值可信度判断
  ↓
必要时重新采样或归零
  ↓
生成定标参数 / LUT
```

推荐的算法演进方向：

1. **保留一维扫描作为快速粗定位手段**；
2. **在峰值附近增加少量二维采样点**；
3. **使用局部二次曲面拟合表达 X/Y 耦合**；
4. **增加拟合残差、曲率、重复性等质量指标**；
5. **把定标结果从单一 Peak 扩展为完整的定标模型**；
6. **结合温度和时间数据构建漂移补偿模型**。

---

## 9. 一句话总结

M576 的 MEMS / DAC 定标，本质不是简单找到一个最大功率点，而是在有限采样、带噪声、带漂移的工程条件下，建立并维护 `DAC(X,Y) → 光学响应 Z` 的稳定映射；传统一维扫描 + 二次拟合适合快速粗定位，但对 X/Y 耦合、平顶、多峰、漂移和非理想光斑存在天然局限，未来更合理的方向是从“一维寻峰”升级为“二维响应面建模 + 可信度判定 + 漂移补偿”的定标系统。
